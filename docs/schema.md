# Attend Schema

## Profile

A Profile represents the account user so that Attend can personalize the workflow across the account.

## Event Type

An Event Type represents the meeting style so Attend can organize the kind of meetings.

## Availability Rule

An Availability Rule represents the free time of a host so that Attend can monitor availability.

## Attention Rule

An Attention Rule represents how a hosts attention should be treated so that Attend can manage a hosts time better

## Booking

A Booking represents this particular person has claimed this particular time for this particular Event Type so Attend can appropriately schedule the meeting
